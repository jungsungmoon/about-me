산업공학과 데이터공학을 전공했고, 대학원 재학 중 AI 경진대회 네 곳에서 수상하면서 배재대·경희대에서 데이터 분석 강의를 시작했습니다. 그 경험이 이어져 데이콘에서 교육 파트를 맡고, 엘리스에서 콘텐츠팀을 이끌며 대기업 AI 교육과 3,000명 규모 해커톤을 설계했습니다. 엠버로드에서는 제조 현장에 센서를 달아 데이터를 모으고 모델을 만들어 작업자에게 가이드를 주는 솔루션 개발을 리드했습니다.

지금은 멀티캠퍼스 SSAFY팀에서 AI 트랙을 운영합니다. 제가 만든 시스템 대부분은 누가 시켜서가 아니라 운영하다 보이는 빈 공간에서 시작했습니다. 채점이 며칠 걸리는 것을 보고 AI 피드백 시스템을 만들었고, 설문 엑셀을 매주 손으로 읽는 것을 보고 만족도 분석 시스템을 만들었고, 사내에 데이터가 없는 것을 보고 교육 과정 안에 데이터 수집 미션을 설계했습니다.

화려한 일보다 "누군가의 반나절을 지키는 일"이 변화의 실체라고 생각합니다. 15기 챌린지 설문에서 "데이터 올리는 데 반나절을 썼다"는 문장을 읽고, 16기에는 사전 다운로드 노트북과 오프라인 베이스라인을 미리 만들어 배포했습니다. 숫자는 근거가 있는 것만 씁니다.

SSAFY AI 피드백 시스템

RUNNING · aibot.ssafy.io 멀티캠퍼스 · 1인 기획/개발/운영

과목평가가 끝나면 답안을 LLM이 채점하고, 개념별로 어디가 약한지 진단해 복습 퀴즈와 튜터 챗봇을 만들어 줍니다.

PROBLEM

900명의 코딩·서술형 답안을 강사가 손으로 채점하면 결과가 나오기까지 며칠이 걸렸고, 개인별 피드백은 엄두를 내지 못했습니다.

SOLUTION

제출 즉시 LLM이 루브릭에 맞춰 채점하고, 취약 개념 리포트와 복습 퀴즈, 튜터 챗봇을 자동으로 만들어 교육생 전원에게 돌려줍니다.

LabHub 만족도 분석 시스템

RUNNING · SSAFY LabHub 멀티캠퍼스 · 기획/파이프라인 개발

매주 들어오는 50여 개의 만족도 설문 파일을 한 번에 읽고, 주관식 응답을 LLM으로 분류해 추이와 이상 신호를 한 화면에 보여줍니다.

PROBLEM

양식이 제각각인 설문 엑셀 50여 개와 주관식 수천 건을 운영진이 매주 직접 읽고 요약했습니다. 중요한 불만은 늦게 발견됐습니다.

SOLUTION

업로드만 하면 파싱, 감성 분석, 시각화가 이어지는 파이프라인을 만들었습니다. 교육생 점수와 AI 분석이 어긋나는 반은 자동으로 표시되고 조치까지 기록합니다.

SSAFY AI 챌린지 — 데이터 수집 미션에서 대회까지

멀티캠퍼스 · 기획/데이터셋/운영

교육생 900여 명이 참가하는 Private Kaggle 대회입니다. 데이터셋 제작부터 리더보드 운영, 상위권 코드 검수까지 전 과정을 맡고 있습니다.

PROBLEM

기수마다 새 데이터셋이 필요했지만 사내에 쓸 수 있는 이미지 데이터가 없었습니다. 15기 설문에는 "데이터 올리는 데 반나절", "저장 공간 부족으로 학습 결과 유실"이 적혀 있었습니다.

SOLUTION

데이터 수집을 1학기 과정 안의 미션으로 설계해 1,019명이 사진 28,655장을 모았고, 퀴즈 17,120개로 재배부해 5인 교차 응답으로 정답을 확정했습니다. 16기에는 사전 다운로드 노트북과 오프라인 베이스라인을 대회 전에 배포했습니다.
